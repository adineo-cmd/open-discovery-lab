# Design — documentation and repo conventions

- Ledger format: one-line findings table (F-# | date | track | finding | status | evidence)
- Research notes: papers/TEMPLATE.md 7-part structure (claim, prior art, method, results, negatives, implications, reproduction)
- Docs style: lab-journal tone matching upstream LibrePhone (terse, factual, first-person field notes)
- Journals: dated files (2026-11-09.md …), findings referenced by F-number
- Status markers: candidate → verified → published
