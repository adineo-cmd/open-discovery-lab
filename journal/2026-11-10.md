# Lab journal — 2026-11-10

## Track A — Bluetooth + TrustZone families (agent session, 2026-11-10)

- Built protobuf-free OTA payload tooling: `payload_manifest.py` (reveals 37
  partitions) + `payload_dump.py`. Two empirical bugs found & documented:
  payload v2 renumbers the manifest (partitions=field 13), and REPLACE_BZ
  (type 1) is **bzip2, not brotli** ("BZh9" magic). Dumper validated
  byte-identical against the reference modem.img extraction (89 ops,
  186 MB, sha256 8a329c30…) before any finding was trusted.
- BT firmware was invisible to the original census (vendor/bt_firmware =
  empty symlink): it lives in a dedicated **`bluetooth` partition (FAT16,
  11 files)**. Two Moselle generations (1.1.2-00064, 1.2.0-00380) + an
  **EVROS family the upstream kernel cannot name** (no "evr" string in
  btqca.c; consumed only by the Android vendor BT HAL, per public
  proprietary-dump evidence + ver_info.txt `wlan_evr: WLAN.EVR.1.0-…`).
  Rampatches are **ELF32 ARM Thumb-2** — the third independent ISA on this
  SoC (Hexagon modem, RISC-V wpss, ARM32 BT).
- TLV headers decode against upstream btqca.h (type=1 patch,
  download_mode=3 QCA_SKIP_EVT_VSE_CC); TLV `entry` field equals ELF entry
  minus Thumb bit → `.mbn` and `.tlv` are the same payload in two
  containers. NVM tag structure documented incl. the vendor-HAL multi-NVM
  path (type-4 enclosing header) upstream btqca.c lacks.
- linux-firmware (listing checked 2026-11-10) has only msbtfw11.* at
  different sizes and **no msbtfw12, no evr\*** — FP6's BT family is not
  covered by linux-firmware.
- TZ partitions (tz/hyp/keymaster/devcfg/uefisecapp/multiimgoem/
  featenabler) are **monolithic AArch64 ELFs — the .mdt/.bXX PIL split is
  gone at the core of the stack**; one build ships QTEE+QHEE
  (`TZ.XF.5.28.0-00021-LANAIAAAAANAZT-1`, OEM git be6181077ac3 — same build
  ID appears publicly only as strings in Xiaomi-family board-info dumps;
  first tie to actual ELFs/segments/hashes). In-tree TAs: soter64,
  smplap64 (Qualcomm's *sample app* shipping in production), GlobalPlatform
  secure-element TAs. featenabler ships twice (partition ELF == merged MDT,
  segments spot-checked identical). No gatekeeper image exists (checked
  negative).
- Census-only discipline held for TZ (versions/segments/hashes/strings; no
  code RE, no DRM content) — boundary written into the doc itself.
- Prior-art verdicts all dated 2026-11-10: GitHub code search shows zero
  public version/architecture/segment analysis of any of these images.
- Pushed: 3b3929a (docs + results/bt-tz-census.json), 630fe6d (tools:
  payload_manifest.py, payload_dump.py, bt_tz_analyze.py).
